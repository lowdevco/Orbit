How to create a key
  1. Open github.com/settings/tokens → Generate new token (classic).
  2. Scopes: read:user, user:email, plus repo (private repos and issues) or public_repo (public only).
  3. Paste it above. Orbit checks it with GitHub, then stores it encrypted. It is never shown again.
